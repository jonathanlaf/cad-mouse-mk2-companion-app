# Changelog

## 0.1.0 — WIP, simulator-tested

### Included

- Offline simulator with deterministic motion scenarios and six-axis traces.
- Interactive 3D cube with view presets, pan, drag, and cursor-centered zoom.
- Profile import/export with native save dialog and JSON validation.
- Native HID discovery and vendor Feature-report transport.
- Firmware/profile handshake and runtime axis/global tuning synchronization.
- Device readback, refresh, reset, disconnect detection, and protocol tests.

### Not yet hardware-validated

- HID enumeration and Feature reports on physical hardware.
- Sensor behavior, calibration, sleep/wake, latency, and reconnect behavior.
- Persistent profile storage and production release packaging.
